What it does

Four systems, one rep at a time

Every part of the coach runs off the same real-time landmark data — nothing here is a canned response.

Pose Detection

MediaPipe tracks 33 body landmarks per frame to compute joint angles across five exercise detectors: squats, push-ups, curls, presses, and lunges.

Voice AI Coach

An LLM reads your live form data and speaks corrections out loud mid-set — so you never have to break form to check a screen.

GROQ · TTS

Engineering notes

Problems worth mentioning

Race condition risk
The video processor writes pose metrics on a background WebRTC thread while Streamlit reads them on its own rerun loop. Fixed with a lock-guarded, copy-on-read metrics object — no torn reads, no stale frames.
Single point of failure
Voice coaching depends on an external LLM API that can go down. Form-issue detection was extracted into a standalone module so rep scoring and the dashboard keep working even if the voice pipeline doesn't.
Upstream API drift
A model this shipped against was deprecated mid-development. The model name lives behind a single config point, so swapping providers or models is a one-line change, not a refactor.
Analytics without a pipeline
Streaks, personal bests, and weekly volume all come from one SQLite table, aggregated client-side with pandas — no separate analytics service to maintain.
